# BULLIT — управление

> Сгенерировано из input map: `godot --headless --path . --script res://tools/gen_docs.gd`.
> НЕ править руками — источник истины код (project.godot + tools/gen_docs.gd).

Мышь — камера ВСЕГДА (yaw; pitch статичный из панели). Esc — отпустить/захватить мышь.

| Клавиша | Действие | Поведение по режимам |
|---|---|---|
| **W** | Движение вперёд (относительно камеры) | Везде. Для финтов кликов — направление «вперёд». |
| **S** | Тормоз / хоккейный стоп / пивот на спину | Бег: плуг/юз. В СКОЛЬЖЕНИИ (Alt) + назад = пивот на спину (езда спиной, скорость сохраняется). Для финтов кликов — направление «назад» (треугольник, финт через конёк). |
| **A** | Движение влево | Везде. Для финтов кликов — направление «влево». |
| **D** | Движение вправо | Везде. Для финтов кликов — направление «вправо». |
| **Ctrl** | Стойка (дриблинг) | Удержание: тяга с капом, ЛКМ/ПКМ/Пробел = финты, укрывание шайбы корпусом. |
| **Alt** | Профиль СКОЛЬЖЕНИЕ | Удержание: velocity поворачивается за корпусом без потерь (руль), тяги нет; укрывание. + назад = пивот на спину (езда спиной). |
| **Shift** | Спринт (удержание) / Рывок (двойное) | УДЕРЖАНИЕ Shift при движении: спринт — скорость и тяга x sprint_speed_mult, тратит бак (sprint_max сек); пустой — недоступен, восстановление вне спринта. ДВОЙНОЕ нажатие Shift = рывок: только при ПОЛНОМ баке, тратит весь (взрывной импульс dash_impulse). Выбор: длинный спринт ИЛИ рывок. |
| **ЛКМ** | ЛКМ — бросок / дриблинг | Вне стойки: тап = кистевой, удержание = щелчок (замах, заряд, клюшка поднимается). Стойка: ТАП = короткий перевод к хвату (внешняя); УДЕРЖАНИЕ = широкий дриблинг (ширина растёт по времени до hold_max, на отпускании боковой шаг); +назад = треугольник-сетап (выход: ЛКМ+вбок в окне — выстрел из-под конька). Воздух: удар в лёд ОТ хвата (широко). |
| **ПКМ** | ПКМ — пас / дриблинг | Вне стойки: пас (тап/заряд с подъёмом); во время замаха щелчка — отмена. Стойка: ТАП = короткий перевод от хвата (внутренняя); УДЕРЖАНИЕ = широкий дриблинг; +вбок у борта (<2.5 м) = банк от борта. Воздух: мягко вернуть К хвату. |
| **Space** | Пробел — подброс / воздух | Стойка, шайба на ВНЕШНЕЙ = подброс (~0.8 м, летит с игроком). Внутренняя = ничего (нужен перевод ЛКМ). +назад (любая сторона) = финт через конёк (за спину -> конёк -> вперёд в клюшку). Воздух: набивание — окно СТРОГО juggle_window до льда + кулдаун. |
| **Q** | Q — фейк влево / силовой | Стойка или с шайбой: фейк корпусом ВЛЕВО (дабл-тап = усиленный). Без шайбы вне стойки: СИЛОВОЙ — телеграф 0.15 с, хит в ближайшего в hit_reach перед собой (импульс по массе x скорости), кулдаун hit_cooldown. |
| **E** | E — фейк вправо / отбор | Стойка или с шайбой: фейк корпусом ВПРАВО (дабл-тап = усиленный). Без шайбы вне стойки: ЧЕСТНЫЙ ОТБОР — видимый телеграф-замах poke_windup, затем окно контакта poke_contact; достаёт шайбу только в конусе перед собой и если не укрыта корпусом; промах = полный кулдаун poke_cooldown. |
| **G** | G — свап на вратаря | Переключение управления полевой<->вратарь (вратарь спавнится при нужде). В роли вратаря: WASD в зоне ворот, Пробел=баттерфляй (+сторона=падение), ЛКМ=ловушка, ПКМ=блин; камера за вратарём. |
| **F1** | F1 — тюнинг-панель | Все параметры; правки автосохраняются в user://skating_params.json (дебаунс 1 с). |
| **F2** | F2 — дебаг-оверлей | Крюк/сектор, состояние и сторона шайбы, окно набивания, трактовка Q/E, стан/фол, луч броска. |
| **F3** | F3 — полигон | Цикл: конусы -> манекены (статик/патруль/вратарь) -> оба -> пусто. |
| **H** | H — смена хвата | Правша/левша (клюшка и правила стороны зеркалятся). |
| **R** | R — шайбу в центр | Дебаг. |
| **P** | P — толчок шайбы | Дебаг: случайный импульс. |
| **T** | T — выстрел в ворота | Дебаг: шайба летит в ближайшие ворота. |
